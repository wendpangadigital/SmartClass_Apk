# SmartClass — Gestion Scolaire

Application de gestion scolaire : bulletins, certificats de scolarité, statistiques et documents administratifs, générés directement depuis l'application.

> 🔧 Les sections **Inscription** et **Abonnement** ci-dessous sont rédigées avec des étapes/tarifs génériques à titre d'exemple — à ajuster selon le fonctionnement réel de l'application avant publication.

---

## 📲 Installation (Android)

En attendant la publication sur le Play Store et l'App Store, l'application s'installe directement via un fichier APK.

1. **Télécharger le fichier** : [Télécharger la dernière version (.apk)](REMPLACER_PAR_LE_LIEN_DE_LA_RELEASE_GITHUB)
2. **Autoriser la source** : à l'ouverture du fichier téléchargé, le téléphone demande d'autoriser l'installation depuis cette source. Accepter.
3. **Ouvrir le fichier** : depuis les notifications ou le dossier *Téléchargements*, ouvrir le fichier `.apk` reçu.
4. **Installer** : appuyer sur *Installer*, puis *Ouvrir* une fois l'installation terminée.

> ℹ️ L'avertissement « source inconnue » est normal pour toute application installée hors Play Store — il disparaîtra une fois l'application publiée officiellement.

**Compatibilité :** Android 8.0 ou supérieur.
**Version actuelle :** `REMPLACER_PAR_LA_VERSION` — mise à jour le `REMPLACER_PAR_LA_DATE`.

## 📝 Inscription

1. Ouvrir l'application et appuyer sur **Créer un compte**.
2. Renseigner les informations demandées (ex. : nom de l'établissement, nom et contact du responsable, mot de passe).
3. Valider l'inscription (ex. : confirmation par SMS ou par e-mail, selon la méthode retenue).
4. Se connecter avec les identifiants créés.
