Installation

Les 4 étapes, dans l'ordre

Android bloque par défaut l'installation d'applications venant d'ailleurs que son magasin habituel. C'est normal : ces étapes débloquent l'installation pour ce fichier précis.

1

Autoriser la source

Au moment d'ouvrir le fichier, le téléphone proposera d'autoriser l'installation depuis cette source. Accepter cette autorisation.

2

Télécharger le fichier

Appuyer sur « Télécharger le fichier .apk » ci-dessus et attendre la fin du téléchargement.

3

Ouvrir le fichier

Depuis les notifications ou le dossier Téléchargements, ouvrir le fichier .apk reçu.

4

Confirmer l'installation

Appuyer sur « Installer », puis « Ouvrir » une fois l'installation terminée. SmartClass est prêt.

L'avertissement « source inconnue » est normal

Il apparaît pour toute application installée hors d'un magasin officiel, pas seulement celle-ci. Il disparaîtra une fois l'application publiée officiellement.
